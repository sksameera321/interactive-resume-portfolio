# Interactive Resume Portfolio

A modern, responsive, and interactive developer portfolio and resume showcase built with clean semantic HTML5, modern CSS3 (Custom Properties, Glassmorphism, Responsive Grid/Flexbox), and Vanilla JavaScript.

## Features

- **Theme Switcher**: Smooth Dark & Light mode toggle with `localStorage` persistence.
- **Interactive Resume Timeline**: Tabbed switcher for Work Experience, Education, and Certifications.
- **Skills Matrix**: Visual proficiency progress bars and categorical skill tag badges.
- **Project Showcase & Filters**: Interactive filter tabs (All, Web Apps, UI/UX) with live repository links.
- **Responsive Layout**: Designed mobile-first, ensuring an optimal viewing experience across mobile phones, tablets, and desktop displays.
- **Interactive Contact Form**: Integrated with direct email links and client-side feedback.

## Running Locally

Simply open `index.html` in any modern web browser or use a live server extension:

```bash
# Using Python built-in HTTP server
python -m http.server 3000

# Or using npx serve
npx serve .
```
