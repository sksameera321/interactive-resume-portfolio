01 / About

Background & Approach

I am a software developer with a primary focus on frontend engineering and web fundamentals. I enjoy taking ideas and translating them into cleanly engineered, responsive web products that load fast and work reliably across all modern devices.

My frontend journey began with a clear curiosity: building my very first web page (project-1) using raw HTML and CSS after completing my intermediate studies with top academic honors (982 marks) and qualifying the engineering entrance exam. What started as simple markup and inline styles ignited a passionate drive toward software engineering.

Since those initial lines of code, I have systematically expanded my engineering horizons — progressing from foundational DOM manipulation to building practical, full-scale applications including e-commerce storefront clones with state persistence, responsive dining platforms, browser gaming portals, and tactile UI design systems like Neumorphism.
